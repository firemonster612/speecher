Welcome to Speecher

Step 1 of 9

Speecher records a short dictation, turns it into text, and sends it to the app you were using.

This assistant checks everything dictation needs: your speech service, microphone, and how text reaches your apps.

Before you start

Speecher uses your existing ChatGPT or Claude sign-in. Install and sign in to one of these, then choose Check again:

  • Codex CLI or the ChatGPT app Sign-in found Not found Checking…

    Sign in with ChatGPT in the ChatGPT app, or install the Codex CLI and run codex login.

  • Claude Code Not found Checking…

    Install Claude Code from claude.com/code and sign in — the desktop app or the claude CLI (/login) both work.
