## New

- First public version of Speecher.
- Speecher now updates itself. Pick a channel in Settings > General >
  Updates: Stable Release (default) or Nightly Build, which is republished
  from every push to master. By default the app only tells you when a new
  version exists and updates when you press the button; a separate toggle
  installs updates in the background if you prefer.
- On Linux, first-run setup starts with a Global Shortcut page. On KDE
  Plasma the shortcut registers itself; on GNOME, Hyprland, and other
  desktops with the GlobalShortcuts portal, one click opens your desktop's
  own binding dialog; everywhere else you get copy-paste instructions.
  AppImage users can also add Speecher to their app menu and PATH from the
  same page.
- After an update, the settings window offers "See what's new", a page with
  the release notes and the new settings themselves, live, so you can try
  them without hunting.
- macOS updates go through Sparkle. The app is still unsigned (see the
  README for the one-time Gatekeeper step), but every update is verified
  against the project's own signing key.

## Changed

- The app identity moved from the placeholder `local.speecher` to
  `io.github.firemonster612.speecher`. Existing settings migrate on first
  launch; the old files are left in place. On Plasma the toggle shortcut
  re-registers under the new identity.
- `speecher --version` now prints the exact build, including the commit a
  Nightly Build came from.

## Fixed

- The bundled helper programs (ydotool setup, Wayland clipboard) now
  resolve correctly when Speecher runs from an AppImage or a build tree.
