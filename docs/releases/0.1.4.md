## Changed

- Settings pages on Linux are laid out as rows: each setting's name and a
  short note on the left, its control on the right, grouped in cards with a
  heading above, the way KDE's own settings pages look. The Applications
  page's rules now live on the Output page, and the Theme row is gone on
  Linux because the desktop decides the theme.
- The sidebar highlight follows your widget style, including rounded
  selections on current Breeze.
- Settings pages widen with the window instead of staying at one fixed
  column width.
- The update and What's New banner, and the warning shown when a setting
  cannot be saved, now look like KDE's inline messages: a tinted strip in
  the message's colour with an icon, the text, its actions and a close
  button.
- When the desktop's widget style is not one the AppImage carries (Breeze,
  Kvantum, Adwaita), Speecher now tries the style plugin installed on the
  system before falling back to Breeze. That works when the system's Qt is
  not newer than the AppImage's; otherwise the log says why it fell back.
  Colours, fonts and icons already came from the desktop.

## Requirements

- The Linux AppImage is now built on Debian's testing branch to ship a current
  KDE stack. It needs glibc 2.43 or newer (Debian 14, Fedora 44, Ubuntu 26.04,
  or later).
