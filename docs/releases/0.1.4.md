## Changed

- Settings on Linux are laid out as cards: each page is a short list of titled
  groups, with a setting's name on the left and its control on the right, so a
  page reads top to bottom instead of as one long form.
- The sidebar has seven pages: Dictation, General, Audio, Output, Accounts,
  Refinement and Vocabulary. The Applications page is gone; its app rules now
  sit on Output beside the paste rules, and `speecher settings applications`
  still opens them there.
- The Global Shortcut editor is the first thing on the Dictation page.
- Help text under a setting is now a single line, and settings whose name says
  it all have none.
- Searching in the sidebar jumps to the one setting that matches and points at
  it.
- On Linux the Theme choice is gone: the desktop decides the colour scheme.
