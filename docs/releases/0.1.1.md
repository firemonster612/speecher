## Fixed

- The Linux AppImage now looks and behaves like a Plasma app: Breeze
  widgets, your colour scheme, your icon theme, and a proper KDE assistant
  dialog. The 0.1.0 AppImage was built without the KDE libraries, which is
  why it came up grey, without icons, and could not register a shortcut.
- Speecher no longer crashes on launch when built from source on a KDE
  desktop with layer-shell-qt installed.
- `make install` on a machine whose system Qt is newer than the one in
  `CMAKE_PREFIX_PATH` now stops with a clear message instead of an obscure
  CMake error, and `SPEECHER_WITH_KDE` fails early when a KDE library is
  missing rather than silently building a lesser app.
- On macOS, releases are signed with one stable identity, so the
  Accessibility permission you grant survives updates. Media pause and
  resume no longer stop working when one player fails, and text is inserted
  only into the field that was focused when you started dictating.
- The updater checks that it can write to the AppImage before offering an
  update, survives a power cut mid-replacement, keeps the file's
  permissions, and forgets a downloaded update when you switch channels.

## Changed

- First-run setup starts with Welcome and ends with the Global Shortcut
  page. On Plasma you press the keys you want and click Set. On desktops
  with the GlobalShortcuts portal, your desktop asks you to pick them.
  Anywhere else, Speecher shows the one command to bind by hand. The last
  page tells you exactly which keys start dictation.
- The Global Shortcut can be changed later from Settings > General.
- "What's New" has a way back, and Settings > General gains "Remove
  Speecher from this computer", which undoes the app-menu entry, the
  `speecher` command, and the shortcut, and offers to delete your settings.
- Settings copy was rewritten in plain language. Rows that need desktop
  accessibility now say so on the page, with the button to turn it on
  beside them.

## Requirements

- The Linux AppImage now needs glibc 2.41 or newer (Debian 13, Fedora 42,
  Ubuntu 25.04, or later). If your distribution is older, it prints a plain
  sentence saying so instead of failing to start.
