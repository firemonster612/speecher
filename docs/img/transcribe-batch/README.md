# Transcribe batch on Linux

Offscreen with the KDE platform theme and Breeze Light in an isolated config.
The processing and results captures come from real ChatGPT Codex runs; the
export error is injected by the test page.

- `configure-window.png`: the compact window with two files, "Apply vocabulary" titled.
- `processing-window.png`: the waveform with its playhead, the percentage and the live partial transcript.
- `results-window-narrow.png`: 440 px wide; names shorten in the middle and details wrap under them.
- `export-error.png`: an export failure in its own message; the summary stays.
