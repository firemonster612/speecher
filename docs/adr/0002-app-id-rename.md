# App id is io.github.firemonster612.speecher, renamed from local.speecher

The original `local.speecher` id was a placeholder that no distribution channel accepts and that the GlobalShortcuts portal (which requires a resolvable reverse-DNS identity backed by an installed .desktop file) and Sparkle (which keys updates on `CFBundleIdentifier`) would both choke on. We renamed to the GitHub-derived id `io.github.firemonster612.speecher` before publishing any artifact, because renaming after users exist breaks settings persistence, macOS app identity, and stored portal permissions all at once. QSettings organization became `io.github.firemonster612`; a one-time startup migration copies settings and app data from the old locations and deliberately leaves the old files in place. Old KGlobalAccel bindings under the `local.speecher` component are orphaned, not migrated; the app re-registers its default on Plasma.
