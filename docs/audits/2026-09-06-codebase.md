# Speecher codebase audit

Audit base: `d43d0bedc89467a337b182a31d395c4335613936`, 6 September 2026.

The costly problems were stale state, incomplete protocol handling, and duplicated settings rules. The three native front ends and the provider/platform seams are justified by real implementations. Removing those interfaces would spread their responsibilities back across callers.

The initial audit covered core settings and text processing, dictation, providers, platform adapters, front ends, output, test infrastructure, and selected build/packaging paths. Two audit agents worked alongside the primary reviewer. One fixer received the consolidated findings. The review used codebase-design, write-less and Ponytail's whole-repository audit, with correctness and performance assessed separately from Ponytail's complexity-only pass.

The suspected ydotool save omission was rejected as an automatic fix. Setup changes that flag directly. Writing an old draft's value back during an unrelated save could undo completed setup. The two deadline tests also needed a correction to the initial report: their timeouts were 60 ms inactivity and 100 ms absolute, not a 60 ms absolute deadline.

Ponytail identified deletions and shared descriptions, rather than grounds for a new transport superclass or a cross-platform UI rewrite. The remaining duplication between the HTTP refiners is a maintenance concern because the cancellation defect appeared in both, but a large inheritance hierarchy would not make their interfaces simpler.

The preview microbenchmark repeats the same seven-word extraction 100 times. For a 100,000-word transcript, the original took about 1.42 seconds and the suffix scan about 0.0075 milliseconds on this machine. This measures only preview extraction, not end-to-end dictation latency. Both returned the same output length; normal tests check the text itself.

The baseline reduced Linux build passed all 21 suites in 22.27 seconds, with Qt reporting 358 passes and 16 explicit skips, including suite setup/cleanup. Full KDE development dependencies were absent, so the build used `SPEECHER_WITH_KDE=OFF`. The isolated KWin fixture captured the AT-SPI target successfully. Its clipboard fallback test could not pass because `wl-paste` was absent. Native macOS/Windows execution, live vendor accounts, microphone hardware, and release packaging require their own environments and are not certified by Linux tests.

Final Linux verification used `cmake --build build -j 4` and `ctest --test-dir build --output-on-failure`. All 21 suites passed in 28.55 seconds. The earlier clean rebuild had no compiler warnings. The targeted settings run passed all three selected functions, with no skips. Default CTest success includes explicit opt-in live-test skips; the two AT-SPI cases were run separately in isolated KWin and passed without skips. General-page screenshots were inspected before and after the changes, with its appearance preserved.

The live AT-SPI work also exposed Qt's UTF-16 offset and InsertText-length behavior. The adapter now handles that separately from the codepoint offsets and UTF-8 byte lengths used for other toolkits. GTK was not exercised live. Verification reads bounded surrounding text rather than copying a whole document.

The first independent review found that a native collection editor could lose concurrent records on its second save even after the model-level merge was corrected. Editors now pass the last record array they successfully submitted as their own baseline. Tests cover repeated saves and an intervening scalar save at the native model/bridge boundary, but require Mac and Windows to execute. Writing-profile metadata also moved onto its schema row, removing native descriptor caches and a merge special case.

Audit artifacts, reproduction logs, benchmark sources, screenshot captures, and both review passes are retained locally under `.scratch/audit/`. Ponytail came from `DietrichGebert/ponytail` at revision `974d940a1c5344210874150b98ff0d2c861fab6a`; its complexity pass was kept separate from correctness findings. No package dependency was removed. Changes are local and uncommitted. This audit records the defects found and the checks performed; it does not establish that every possible defect has been found.

Independent GPT and Fable reviews covered both the implementation requirements and code standards in two passes. The second pass agreed that the retained-editor baseline and schema descriptor fixes were correct. Both found the same remaining macOS fallback ambiguity: a persistent floating window can keep the same topmost window ID while keyboard focus changes between documents. The final correction makes the no-accessibility fallback decline ambiguous multi-window cases. This deliberately favors clipboard-only delivery over pasting into the wrong document. Native interaction remains unverified.

Standards review ended with one corroborated P2 finding in the second-pass snapshot, addressed by the final fallback correction. Spec review identified that same target-safety requirement as incomplete in the snapshot; the final correction addresses it. The small correction was inspected directly after the two independent passes, with no third review wave. No other accepted finding remains open in source. Native compilation and interaction checks remain outstanding as described above.
