A. Inline diff in the popup, with voice follow-ups

The capsule grows into a card, as an error's does. A long selection folds to the changed stretches; when most words changed it shows the revised text alone. Pressing the Global Shortcut dictates a follow-up: the footer turns into today's listening row, then Refining, and the card returns with the diff against the original selection. Esc while following up drops the follow-up and keeps the previous revision. Click the shortcut chip to try it.
