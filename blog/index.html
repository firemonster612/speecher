Speecher 0.1.0

Sep 3, 2026

Today we're releasing Speecher 0.1.0, the first public version of Speecher, a dictation app for Linux and macOS that runs on the Claude Code or ChatGPT subscription you already pay for. We plan to release substantially smaller improvements in the coming weeks, mostly to fix the things this release breaks.

Speecher 0.1.0 is available now as an AppImage for Linux and a DMG for macOS. It's also on GitHub, which is the only place it is. Pricing is the same as before: there isn't any.

Speecher 0.1.0

Speecher advances our state-of-the-art in getting words out of your mouth and into whatever app has your cursor. Press a shortcut, talk, and clean text lands where you were typing. It also improves Speecher's handling of spoken edits, especially "scratch that", and it learns your own vocabulary so it stops spelling your project names wrong.

Enzo notes that Speecher 0.1.0 improves across most capabilities relative to Speecher 0.0.0, which did not exist, with particularly notable gains in existing. Enzo's terminal reports that Speecher pinpoints the exact text field without pasting into the wrong window, with the team (also Enzo) preferring this precision for everyday dictation. A Plasma desktop in the test fleet finds the global shortcut registers itself on first run, showing roughly the same leap as the jump from "not installed" to "installed".

Here is what 0.1.0 ships, taken from the release notes rather than from memory:

  • Speecher updates itself. Pick Stable Release or Nightly Build in Settings. By default it only tells you a new version exists and waits for you to press the button.
  • On Linux, first-run setup starts with a Global Shortcut page. Plasma registers the shortcut itself. GNOME, Hyprland and other desktops with the GlobalShortcuts portal get one click into their own binding dialog. Everywhere else gets copy-paste instructions.
  • After an update, the settings window offers "See what's new", with the release notes and the new settings themselves, live.
  • macOS updates go through Sparkle and are verified against the project's own signing key. The app is still unsigned, because there is no Apple Developer account.
  • The app identity moved to io.github.firemonster612.speecher. Existing settings migrate on first launch.
  • speecher --version prints the exact build, including the commit a Nightly Build came from.
  • The bundled helper programs now resolve correctly when Speecher runs from an AppImage.

Getting started

We recommend upgrading from nothing to Speecher 0.1.0 for all uses. On Linux, download the AppImage, make it executable and run it. On macOS, open the DMG, drag Speecher to Applications, then tell Gatekeeper you meant it under System Settings, Privacy & Security, Open Anyway. If you're a developer, simply make install. You can also explore our README, release notes, product page, and source to learn more.

Transcription needs a Claude Code or ChatGPT sign-in on the same machine. Speecher does not ship a model of its own. We think that is the whole point.

As always, your feedback helps us improve, especially the bug reports. Especially those.

Benchmark reporting

Speecher is not a hybrid reasoning model. The results in this blog post show the highest scores achieved with or without coffee. We've noted below for each result whether coffee was used:

  • With coffee: all of them

Comparison methodology

Scores were achieved by one person dictating into a terminal on a Thursday. To accommodate the additional retries a first release incurs, the maximum number of attempts was increased from 30 to 100 (most dictations completed on the first attempt, with only one reaching above 50, and that one was the microphone's fault). We did not run the comparison apps. We read their pricing pages, which is the only benchmark most people run anyway. n=1.

Our Responsible Dictation Policy

Screenshot context is off by default and never stored. API keys live in your system keyring, not a config file. Your clipboard comes back after Speecher pastes. Updates ask before they install. We wrote these down on the product page so we would have to keep doing them.

Building it yourself

Speecher is Qt Widgets on Linux and SwiftUI in the macOS menu bar, not a web view. If you'd rather compile than download, the README lists the packages for Arch, Debian, Fedora and Homebrew, and make install does the rest.
