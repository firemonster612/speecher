Speecher UI preview

The new Qt Quick front end on pretend data. Nothing here records audio,
pastes text or touches your settings; buttons that would do those things
change the pretend state or show a toast instead.

Needs uv: https://docs.astral.sh/uv/getting-started/installation/
  Linux/macOS:  curl -LsSf https://astral.sh/uv/install.sh | sh
The first run downloads PySide6 (about 200 MB) into uv's cache.

Run, from this folder:
  bash try.sh            the main window (Ctrl+K searches settings)
  bash try.sh setup      the setup assistant
  bash try.sh popup      the dictation popup, playing on a loop
  bash try.sh gallery    every shared control
On Windows use .\try.ps1 the same way.

Add --theme=dark for the dark theme, or --reduce-motion=true to see the
reduced-motion version. General > Appearance also switches theme live, and
General > Setup assistant opens setup from the main window.
